## 2. สูตรการต่อสู้

### 2.1 ความเสียหาย

```
Raw      = ATK × SkillMult
DefRed   = K / (K + DEF_target)            K = 500 + 10 × AttackerLevel
ElemMult = 1.3 (ได้เปรียบ) / 1.0 / 0.8 (เสียเปรียบ)
Crit     = roll < CritRate ? CritDMG : 1.0

Damage   = Raw × DefRed × (1 + ElementDMG%) × ElemMult × Crit × ΠModifiers × Random(0.95, 1.05)
```

- `ΠModifiers` = ผลคูณของ Affix, Path Trait, Set Bonus ที่เป็นตัวคูณความเสียหาย
- ตัวอย่าง: มังกร Lv 100 DEF 1,070 รับดาเมจจากศัตรู Lv 100 (K = 1,500) → ลดดาเมจ ≈ 42%

### 2.2 จังหวะ

| ค่า | สูตร |
|---|---|
| ระยะห่างโจมตีปกติ | `1.6 วินาที × 100 / SPD` (SPD 130 ≈ 1.23 วินาที) |
| คูลดาวน์สกิล | `BaseCD × 100 / (100 + SkillHaste)` |
| โอกาสหลบอัตโนมัติ | `clamp((SPD − SPD ศัตรู) × 0.2%, 0, 25%)` + โบนัส Trait · เพดานรวม 40% |
| เกจสัญญา (Command) | เต็ม 100 · +2 ต่อการโจมตีที่โดน · +1 ต่อ HP ที่เสีย 1% · +10 เมื่อหลบสำเร็จ |
| เพดาน | CRIT Rate 100% · Skill Haste 100 · ลดดาเมจจากโล่/Trait รวมไม่เกิน 70% |

### 2.3 การรวมค่าพลังสุดท้าย

```
Final = (Base_dragon + ΣFlat) × (1 + ΣPercent)
```

- `ΣFlat` = Main/Sub stat แบบตัวเลขจากอุปกรณ์
- `ΣPercent` = % จากอุปกรณ์ + Pact Buff ผู้ใช้ (หลัก + สนับสนุน) + Path Trait + Set Bonus — **รวมแบบบวกในกลุ่มเดียว** เพื่อให้คาดเดาและปรับสมดุลง่าย
- Affix ของดันเจี้ยนเป็นตัวคูณแยก (ใน `ΠModifiers`)

### 2.4 Power Score (แสดงใน UI)

```
Power = ATK × 1.0 + HP × 0.1 + DEF × 1.5 + (SPD − 100) × 20
      + ATK × (CritRate × (CritDMG − 1)) + ATK × ElementDMG% × 0.8
```

ใช้เพื่อการสื่อสาร (เช่น "พลังแนะนำ" ของแต่ละชั้น) เท่านั้น ไม่ใช้ในการคำนวณการต่อสู้

## 3. Affinity และ Path

### 3.1 สูตร

```
EquipAffinity = floor(RarityBase × (1 + 0.05 × EnhanceLevel))
RiderAffinity = floor(RiderBaseAffinity × StarMult[star])
PathAffinity  = Σ EquipAffinity (Path เดียวกัน) + RiderAffinity (ผู้ใช้หลักเท่านั้น)
```

| Tier | เกณฑ์ Affinity |
|---|---|
| I | 20 |
| II | 60 |
| III | 120 |
| IV | 200 |
| Path Resonance | 2 Path ≥ 60 (UR ออรีออน: ≥ 40) |

|---|---|---|---|
| ต้นเกม (Stage 1) | หายาก +9 ×3 (Fury) = 39 | ทิม (R, ไม่มี Affinity) | Fury Tier I |

## 5. ดันเจี้ยนรายสัปดาห์

### 5.1 ระดับหอคอย (Bracket)

ผู้เล่นทุกระดับต้องสนุกกับหอคอยได้ จึงแบ่ง **Bracket ตาม Stage ของมังกร ณ เวลารีเซ็ต** (ล็อกไว้ทั้งสัปดาห์ — วิวัฒนาการกลางสัปดาห์ไม่ทำให้หอคอยยากขึ้นทันที)

| Bracket | Stage มังกร | เลเวลศัตรูชั้น 1 → 30 | ความหายากรางวัลสูงสุด |
|---|---|---|---|
| B1 | 1 | 5 → 25 | มหากาพย์ |
| B2 | 2 | 20 → 45 | ตำนาน |
| B3 | 3 | 40 → 65 | ตำนาน (+ เทพนิยาย 1%) |
| B4 | 4 | 60 → 85 | เทพนิยาย 5% |
| B5 | 5 | 80 → 100 | เทพนิยาย 10% |

### 5.2 การเพิ่มความยากต่อชั้น

```
EnemyStat(f) = BracketBase × 1.06^(f − 1)          // ชั้น 1–30
EnemyStat(f) = EnemyStat(30) × 1.08^(f − 30)        // ชั้นอนันต์ 31+
Guardian (10, 20) = ×2.5 HP · Boss (30) = ×6 HP และมีกลไกพิเศษ
```

**ความยากเป้าหมาย:** ชั้น 20 ผ่านได้ด้วยอุปกรณ์มหากาพย์ +9 ที่ Path ตรงกับบอส · ชั้น 30 ต้องใช้ Path + ธาตุที่ถูกต้อง หรืออุปกรณ์ตำนาน +12 ขึ้นไป

### 5.3 รางวัลเคลียร์ครั้งแรก (ต่อชั้น `f`, Bracket `b`)

| รางวัล | สูตร |
|---|---|
| ทอง | `1,000 × b × (1 + f / 10)` |
| ศิลาตีเหล็ก | `(5 + f) × b` |
| แก่นมังกร | `3 + floor(f / 3)` |
| ผลึกธาตุ (ธาตุตามธีม) | `2 + floor(f / 5)` |
| ตราสัญญา | +1 ทุกชั้นที่หาร 5 ลงตัว (รวม 6 ต่อสัปดาห์) |
| อุปกรณ์ | 1 ชิ้นทุกชั้น ความหายากตามตารางด้านล่าง |

| ช่วงชั้น | หายาก | มหากาพย์ | ตำนาน | เทพนิยาย |
|---|---|---|---|---|
| 1–9 | 60% | 35% | 5% | — |
| 11–19 | 30% | 55% | 15% | — |
| 21–29 | — | 60% | 38% | 2% |
| ผู้พิทักษ์ 10 / 20 | — | 50% | 50% | — |
| บอส 30 (ชิ้นในชุด) | — | — | 90% | 10% |

> ความหายากถูกจำกัดด้วยเพดานของ Bracket (§5.1) — เกินเพดานให้ลดเป็นระดับสูงสุดที่อนุญาต

### 5.4 การกวาดชั้น (Sweep) และบอส

| กวาดชั้น (1 คบเพลิง) | 50% ของวัตถุดิบเคลียร์ครั้งแรก + 20% โอกาสได้อุปกรณ์ (ไม่ได้ตราสัญญา) |

## 7. อุปกรณ์

### 7.1 Main Stat

```
MainStat(enhance) = MainBase × (1 + 0.10 × enhance)      // +15 = ×2.5
```

| ความหายาก | ATK (กรงเล็บ) | HP (เกราะอก) | DEF (หาง) | % stat (เขา/ปีก/หัวใจ) | SPD (ปีก) |
|---|---|---|---|---|---|
| ธรรมดา | 30 | 300 | 15 | 3% | 3 |
| ดี | 50 | 500 | 25 | 4% | 4 |
| หายาก | 80 | 800 | 40 | 6% | 6 |
| มหากาพย์ | 120 | 1,200 | 60 | 8% | 8 |
| ตำนาน | 170 | 1,700 | 85 | 10% | 10 |
| เทพนิยาย | 230 | 2,300 | 115 | 13% | 12 |

- Main stat แบบ CRIT Rate = 50% ของค่า % stat · CRIT DMG = 150% ของค่า % stat

### 7.2 Sub-stat (ช่วงสุ่มต่อครั้ง)

| Sub-stat | ช่วง |
|---|---|
| ATK% / HP% / Element DMG% | 2–4% |
| DEF% | 3–5% |
| CRIT Rate | 1.5–3% |
| CRIT DMG | 3–6% |
| SPD / Skill Haste | 1–3 |
| ATK / HP / DEF (flat) | 8–15 / 80–150 / 4–8 |

ที่ +3/+6/+9/+12/+15: ถ้า sub-stat ยังไม่ครบ 4 ค่า → เพิ่มค่าใหม่ · ถ้าครบแล้ว → สุ่มอัปค่าเดิม 1 ค่า

### 7.3 ค่าตีบวก

```
ศิลาตีเหล็ก(n → n+1) = ceil(5 × 1.25^n) × RarityCostMult
ทอง = 200 × ศิลาตีเหล็กที่ใช้
```

| ความหายาก | RarityCostMult | ศิลารวม +0 → +15 (≈) |
|---|---|---|
| ธรรมดา | 0.5 | 278 |
| ดี | 0.75 | 416 |
| หายาก | 1.0 | 555 |
| มหากาพย์ | 1.5 | 833 |
| ตำนาน | 2.0 | 1,110 |
| เทพนิยาย | 3.0 | 1,665 |

### 7.4 หลอมทิศทาง / ย่อยสลาย

| การกระทำ | ค่าใช้จ่าย / ผลตอบแทน |
|---|---|
| หลอมทิศทาง | ผลึกธาตุ = `ceil(0.3 × ศิลาที่ลงทุนไปแล้ว / 5)` + แก่น Path ปลายทาง (หายาก 5 · มหากาพย์ 10 · ตำนาน 20 · เทพนิยาย 40) |
| ย่อยสลาย | คืนศิลาตีเหล็ก 80% + แก่น Path ของชิ้นนั้น (หายาก 1 · มหากาพย์ 2 · ตำนาน 5 · เทพนิยาย 10) |

### 9.3 ผลต่อเศรษฐกิจ

- ค่าเฉลี่ยต่อครั้ง (สมมติชนะตัวหายากทุกครั้ง) ≈ ทรัพยากรตัวปกติ × 1.8 → ผู้เล่นที่ใช้พลังล่าครบวันละ ~48 ครั้ง ได้ศิลาตีเหล็กราว `260 × z` ต่อวัน
- ไม่ดรอป **เกล็ดโบราณ** และ **ชุดอุปกรณ์ประจำธีม** — สองอย่างนี้ยังเป็นเหตุผลให้ลงหอคอยรายสัปดาห์
- ร้านค้าขายพลังล่าเพิ่มได้วันละไม่เกิน 2 ครั้ง (ครั้งละ 60) — ให้ตัดสินใจร่วมกับ Monetization
