# Path to Dragon — รายงานจำลองสมดุล (Balance Simulation)

> สร้างจาก `BalanceSimulator` (เมนู **P2D → Balance Simulator** ใน Unity) · 20 รอบต่อชั้น ต่อ Build · ศัตรูธาตุไฟ (สัปดาห์ภูเขาไฟคำราม) · มังกรใช้แก่นหัวใจธาตุน้ำ
> สมมติฐานและค่าศัตรูอยู่ที่ [Balance.md §11](Balance.md#11-เครื่องมือจำลองสมดุล) — รันใหม่ทุกครั้งที่แก้ตัวเลขสกิล อุปกรณ์ หรือศัตรู

## สรุปผล

| ประเด็น | ผล | สถานะ |
|---|---|---|
| จังหวะความคืบหน้า | Build สัปดาห์ที่ 3 (Stage 2 มหากาพย์ +9) ไต่ได้ชั้น 26–30 ตรงเป้า "B2 ชั้น 25–30" · ของต่ำ (หายาก +6) ติดที่ชั้น 21 | ✅ ตรงเป้า |
| บอสชั้น 30 | ต้องใช้ทั้ง Build ที่ดีและการหลบ: B4 Fury ชนะ 20% แบบ Auto → 80% เมื่อผู้เล่นหลบได้ 80% · ของต่ำชนะ 0% | ✅ ตรงเป้า |
| Bastion | ช้าที่สุด (บอส 80–107 วินาที จากเวลาจำกัด 120) แต่ชนะบอส 100% แม้ไม่หลบ — สาย "ช้าแต่ชัวร์" | ⚠️ เฝ้าดู: ช้าเกือบชนเวลาจำกัดที่ B4 |
| Arcane | เคลียร์เร็วที่สุดทุกช่วง (ชั้น 10 ใน 0–7 วินาที) แม้ปรับลดแล้ว | ⚠️ อาจต้องลดอีก |
| Tempest | อ่อนที่สุดใน B2/B4 (ชั้น 26/28) — ส่วนหนึ่งเพราะผู้ใช้สาย Tempest ใน GDD มีแค่ SR (ลีร่า) ขณะที่สายอื่นใช้ SSR | ⚠️ ควรมีผู้ใช้ SSR สาย Tempest |
| ไฮบริด | Fury+Tempest (Resonance เพลิงพายุ) ดีเท่าหรือดีกว่าสายเดียวที่ B4 | ✅ ไฮบริดเป็นทางเลือกจริง |

## การปรับที่ทำจากผลจำลองรอบนี้

- **Bastion:** หางพิฆาต +12% HP สูงสุดเป็นดาเมจ (คูลดาวน์ 8 → 6 วิ) · Trait II เพิ่มดาเมจโจมตีปกติ +3% HP สูงสุด · Trait III สะท้อน 15% → 20% · ป้อมปราการนิรันดร์โจมตีทั้งหมด 150% + 10% HP สูงสุด (เดิมไม่มีดาเมจ จนแพ้เพราะหมดเวลา)
- **Arcane:** ลูกแก้วรูน Element DMG +30% → +20% · สายฟ้าดารา 130% → 110% · ฝนดาราจักร 150% → 120% ต่อฮิต
- **ศัตรู:** ผู้พิทักษ์ HP ×4 → ×3, ATK ×1.8 → ×1.5 · บอส HP ×9 → ×4, ATK ×2.0 → ×1.0 (เดิมไม่มี Build ไหนชนะบอสได้เลย)
- **แก้บั๊ก:** ค่าที่เป็นอัตราอยู่แล้ว (CRIT, Element DMG) เคยถูกคูณแทนการบวก
